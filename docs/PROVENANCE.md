# Source provenance

This implementation was authored with AI assistance using Kotlin, Android APIs and the Bluetooth LE Glucose Service approach. An owner-supplied earlier Bio Track preview APK was examined to understand its behavior when its source was unavailable. This is not represented as a formally audited clean-room process.

A separately supplied APK labelled as a mySugr reference was identified as an Aptoide package during metadata inspection. No mySugr application source, proprietary graphics or extracted manufacturer assets are included in this repository. Supplied APKs, decompilation outputs, personal exports and signing material are excluded.
