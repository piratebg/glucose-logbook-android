# Security reporting

This experimental project has no guaranteed security-support response time. Use GitHub private vulnerability reporting if it is enabled on this repository. If no private channel is offered, first open a public issue asking for a private contact, without exploit details, health data or identifiers. Do not publish sensitive material while arranging contact.

Include affected source version, Android version, impact and a minimal synthetic reproduction. Never send real glucose records, credentials, signing keys, meter serial numbers or Bluetooth addresses. Public bugs that do not involve sensitive information can use the normal issue template.

Keep devices and Android up to date, protect exported files, and inspect source changes before installing a self-built APK. The project does not claim a completed independent security audit.
